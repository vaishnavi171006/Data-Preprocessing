# Data Preprocessing using Python

## About
This project demonstrates data preprocessing techniques used in Machine Learning to prepare raw data for analysis and model building.

## Objectives
- Understand and inspect a dataset.
- Handle missing values.
- Remove duplicate records.
- Encode categorical variables.
- Apply feature scaling where required.

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn

## Experiment
The Jupyter Notebook contains the code, implementation steps, and outputs for the data preprocessing experiment.

## Learning Outcome
Learned how to clean and transform raw data into a suitable format for machine learning.
